Detailed Description

Rappresenta un'aula didattica o laboratorio prenotabile.

Identificata univocamente dal codice (2-15 caratteri alfanumerici o trattini, memorizzato in maiuscolo). Conserva la denominazione dell'edificio come stringa per consentire sia l'uso libero sia la validazione tramite anagrafica edifici (ED2.1, ED2.2).

Invariant
codice != null && !codice.isBlank()
nome != null && !nome.isBlank()
edificio != null && !edificio.isBlank()
piano != null && !piano.isBlank()
capienza > 0
