Detailed Description

Rappresenta un'aula didattica o laboratorio prenotabile.

Ogni aula è identificata univocamente dal proprio codice e contiene informazioni relative alla denominazione, all'edificio in cui si trova, al piano e alla capienza massima.

L'edificio è rappresentato direttamente mediante un oggetto Edificio, consentendo di mantenere il collegamento con la relativa anagrafica.

Invariant
codice != null && !codice.isBlank()
nome != null && !nome.isBlank()
edificio != null
piano != null && !piano.isBlank()
capienza > 0
