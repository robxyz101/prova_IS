\doxysubsection{Detailed Description}
Rappresenta un\textquotesingle{}aula didattica o laboratorio prenotabile. 

Identificata univocamente dal codice (2-\/15 caratteri alfanumerici o trattini, memorizzato in maiuscolo). Conserva la denominazione dell\textquotesingle{}edificio come stringa per consentire sia l\textquotesingle{}uso libero sia la validazione tramite anagrafica edifici (ED2.\+1, ED2.\+2).

codice != null \&\& !codice.is\+Blank() 

nome != null \&\& !nome.is\+Blank() 

edificio != null \&\& !edificio.is\+Blank() 

piano != null \&\& !piano.is\+Blank() 

capienza \texorpdfstring{$>$}{>} 0 
\end{DoxyInvariant}
